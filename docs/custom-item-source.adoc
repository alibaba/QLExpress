=== 多字符符号运算符的词法规则

当自定义运算符由符号字符组成（例如 `**`、`?.`、`*-`）时，词法器会按**最长已注册前缀**规则匹配，而非贪婪合并所有相邻的运算符字符。只有通过 `addOperator`、`addOperatorBiFunction` 等 API 注册过的符号序列才会被合并为一个 OPID token，否则按单个字符拆分。

这保证了诸如 `10*-1`、`5+-3`、`a/-b` 这类"二元运算符后紧跟一元前缀"的表达式能够被正确解析为 `10 * (-1)`、`5 + (-3)`、`a / (-b)`，无需在中间加空格。

== 说明与建议

- QLFunctionalVarargs 的定义模式下，扩展函数调用时实参列表首位是接收者对象，其后为调用参数；函数与操作符不含接收者。
- 自定义操作符的优先级需根据表达式期望进行设置，避免与已有运算规则产生混淆。
- 注解方式注册仅会处理公开方法，且重复名称将注册失败；批量注册返回结果中包含成功与失败清单。
